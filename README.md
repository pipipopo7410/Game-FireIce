# 元素小勇者｜平板安裝版
基於實測成功的 v1.0 魔法陣輕量化版（384 × 384），未採用 v1.1 系列的辨識或繪圖架構。

## 安裝
1. 解壓縮，將所有檔案（包含 `.nojekyll`）上傳到 Element-Hero 倉庫根目錄。確認 GitHub Pages 已啟用（例如 main / root），使用 HTTPS 網址。
2. iPad 使用 Safari 開啟該網站；分享 → 加入主畫面 → 如有「以網頁 App 開啟」請開啟 → 加入。
3. 從主畫面圖示啟動，橫放平板並允許前置攝影機。固定支架、留出空間，輕鬆揮手即可。

## 說明
- 預設使用原有流暢畫質，取消畫質切換 UI；遊戲畫面保留十顆愛心與交換左右手圖示。回到 App 時會先暫停，點三角形繼續。
- 圖示：180px Apple touch icon、192px 和 512px PWA icon；使用原有冰火魔法陣美術。
- 不包含返回教學網站按鈕。
- 本體可快取，離線觸控試玩；手勢 AI 仍由原 CDN 下載，攝影機玩法需網路，未保證完全離線。
- iPadOS 可能不遵從橫向設定，請手動橫放。若從背景回來相機已中斷，可重新啟動攝影機。
- 保留原始相機畫面不顯示、不錄影、在裝置內辨識的設計；沒有新增上傳影像的流程。
